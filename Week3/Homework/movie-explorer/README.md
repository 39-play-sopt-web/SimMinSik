# 3주차 영화 탐색 과제

지난 과제에서 Emotion을 사용해봤지만, 필요한 스타일을 바로 조합할 수 있는 Tailwind가 저에게는 더 편했습니다. 그래서 이번에는 화면 스타일을 Tailwind로 작성하고, 과제 조건인 ThemeProvider와 GlobalStyle은 Emotion으로 적용했습니다.

## 실행

```sh
npm install
npm run dev
```

프로젝트 폴더의 `.env`에 아래 값을 설정합니다. `.env`는 커밋하지 않습니다.
API 키 문구는 예시이므로 본인이 발급받은 키로 바꿔 넣습니다.
`VITE_` 환경 변수는 브라우저에 전달되므로 서버 전용 비밀값을 넣으면 안 됩니다.

```dotenv
VITE_API_BASE_URL=https://api.themoviedb.org/3
VITE_API_KEY="이거슨_저의_api_키 입니다."
```

## 검사

```sh
npm run typecheck
npm run lint
npm run build
```

현재 공통 레이아웃, 목록·상세 라우팅과 TMDB 영화 목록 조회를 구현했습니다.
목록은 선택한 최소·최대 평점(10점 만점) 범위를 인기순으로 표시하고, 하단에 가까워지면 다음 페이지를 추가합니다.
평점 변경 시 첫 페이지부터 다시 조회하며, 추가 조회 실패 시 기존 목록을 유지하고 같은 페이지를 재시도합니다.
상세 페이지는 영화 ID로 조회한 포스터·배경·장르·평점·상영 시간·투표 수·상태·줄거리를 표시합니다.
기본 정보 영역에는 원제·원어·제작 국가·사용 언어·예산·수익을 표시합니다.
언어와 국가는 한국어로 표시하고, 예산·수익은 미국 달러(USD) 기준으로 표시합니다.
